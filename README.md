# MediaVault — releases

Installers and update packages for **MediaVault**. Download the latest version from the
[Releases page](https://github.com/M789K/mediavault-releases/releases/latest):

- **Windows:** `MediaVault.Desktop-win-x64-Setup.exe`
- **Linux:** the `.AppImage` file (make it executable, then run it)
- **macOS (experimental):** the `.pkg` for your Mac (Apple Silicon: `osx-arm64`, Intel: `osx-x64`)

The installed app updates itself from this page.

---

ملفات تثبيت **MediaVault** وتحديثاته. نزّل آخر إصدار من
[صفحة الإصدارات](https://github.com/M789K/mediavault-releases/releases/latest):
ويندوز `Setup.exe`، لينكس `AppImage`، ماك (تجريبي) `.pkg`. البرنامج المتثبت بيحدّث نفسه من الصفحة دي.
